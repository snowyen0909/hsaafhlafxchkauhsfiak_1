# 宿舍房间素材工具（牆壁／地板拆解重組）

產生 `ContentMod/dorm/walls/`、`ContentMod/dorm/tiles/` 與 `ui2/bt_*.png` 的腳本。路徑寫死在各腳本開頭，換機器時請改。

- `walls2.py` / `compose.py`：把每種牆壁（1032×717，每格 128 px，地板後角在 (516,185)）沿牆切成直條，找接縫最不明顯的位置插入重複段，拼成 10×10、12×12 的牆。`plans.json` 是選中的插入點。
- `review.py N`：輸出某尺寸 6 種牆的預覽。
- `cut_floors.py`：把 6 種整張地板切成 8×8 格（每格 130×66，含 1 px 出血）＋前緣厚度片（64×44），並從新素材圖切出 10 種單片瓷磚（`tile_geo.json` 是頂面四角座標）。
- `preview.py`：用切好的素材在 Python 裡拼出房間預覽，對照遊戲內效果。
- `buttons.py`：從按鈕素材圖去背、抹掉文字（遊戲內用簡體重新寫字）。
- 隱藏牆壁用的踢腳線圖 `*_base.png`：保留牆壁圖中地板線以上 17 px。
