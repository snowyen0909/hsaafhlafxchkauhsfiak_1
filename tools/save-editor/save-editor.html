植物娘存檔修改器

讀取遊戲的 user1.dat，修改金幣、冒險進度、商店物品和花圃植物，再存成新檔放回遊戲。所有處理都在這個頁面裡完成，檔案不會上傳到任何地方。

存檔

示範存檔
存檔在哪裡？
  1. 先在遊戲裡回到主選單，然後從多工畫面把遊戲完全關掉，否則遊戲退出時會蓋掉你改好的檔案。
  2. 按「選擇存檔」，在「檔案」裡進入 我的 iPhone › 植物娘大战僵尸 › docs › userdata，選 user1.dat（第二個玩家是 user2.dat，以此類推）。
  3. 改完按「存成新檔」，會得到一個 zip。在「檔案」裡點一下 zip 解壓，把裡面的 user1.dat 搬回 userdata 資料夾並選擇取代。
  4. 建議先把原本的 user1.dat 複製一份備份。
